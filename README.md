# SentinelCore Application

This repository contains both the frontend and backend components of the SentinelCore application.

---

## 📁 Project Structure

* **`/` (Root folder)** & **`/src`**: The Spring Boot Java backend framework.
* **`/frontend`**: The React-Vite user interface folder.

---

## 🚀 How to Run the Project Locally

### 1. Backend (Spring Boot)
* Open the root folder (`sentinelcore`) in **IntelliJ IDEA**.
* Make sure you have **Java 17+** configured.
* Run the `SentinelCoreApplication.java` file to start the server.
* The API will be accessible at: `http://localhost:8080`

### 2. Frontend (React + Vite)
* Open a terminal window and move into the frontend directory:
  ```bash
  cd frontend
  ```
* Install all required system packages:
  ```bash
  npm install
  ```
* Run the web server in development mode:
  ```bash
  npm run dev
  ```
* Open your browser and navigate to the local address shown in your terminal (typically `http://localhost:5173`).
